# Community Handbook Roadmap

> This is a repository planning file. It is not published as a website page.

This file lists useful master handbooks that are missing from the current library. It helps contributors choose work that can benefit students, beginners, career changers, and self-learners.

Do not create every file at once. A smaller handbook with clear, verified teaching is better than a large collection of empty headings.

## Before Creating a New Master Handbook

1. Search `assets/handbook/` and make sure the subject is not already covered.
2. Open `currentstatus.md` and check whether an existing handbook should be improved instead.
3. Open an issue or discussion so two contributors do not write the same handbook.
4. Follow `handbook_review_and_improvement_guide.md`.
5. Use simple English and explain technical words when they first appear.
6. Start with prerequisites, then move from beginner to intermediate and advanced topics.
7. Add small examples before large examples.
8. Include common mistakes, safe practices, exercises, and troubleshooting where useful.
9. Verify changing technical information with official documentation.
10. Add the new file to the correct subject folder. The website will discover it automatically.

## Definition of Ready

A proposed handbook is ready to begin when:

- A contributor understands the subject well enough to teach it.
- The scope and target learner are clear.
- Important primary sources have been identified.
- No existing handbook already covers the same material.
- The contributor can provide explanations, examples, exercises, and review evidence.

## Definition of Done

A new master handbook is done only when it passes the completion checklist in `handbook_review_and_improvement_guide.md`. After creation, add its review record to `scripts/handbook-review-status.json` and regenerate `currentstatus.md`.
